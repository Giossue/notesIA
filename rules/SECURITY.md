# Reglas de seguridad

- Denegar por defecto.
- Secrets solo servidor/secret manager.
- Redactar logs.
- Autorizar por recurso y rol.
- Sesiones revocables y rotatorias.
- Validar deep links/redirects.
- Limitar cuerpo y frecuencia.
- No interpolar SQL.
- No revelar existencia de email.
- Lockfile y revisión de dependencias.
- Prueba negativa para toda ruta privada.
- No registrar request/response crudos de IA.
