# Workflow: agregar una función

1. Definir problema y usuario.
2. Completar `templates/FEATURE_SPEC.md` si afecta más de un módulo.
3. Marcar alcance/no alcance.
4. Mapear datos, API, seguridad, offline e IA.
5. Diseñar el cambio vertical mínimo.
6. Actualizar contrato/migración primero cuando aplique.
7. Implementar servidor y pruebas.
8. Implementar UI y estados.
9. Añadir observabilidad.
10. Ejecutar definición de terminado.
11. Crear ADR si cambia una decisión estructural.
