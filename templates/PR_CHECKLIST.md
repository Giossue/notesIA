# Checklist de PR

- [ ] Requisito enlazado.
- [ ] Cambio pequeño y enfocado.
- [ ] Sin secrets/PII.
- [ ] Contrato actualizado.
- [ ] Migración segura.
- [ ] Autorización/scoping probados.
- [ ] Idempotencia/versionado revisados.
- [ ] Estados UI/accesibilidad.
- [ ] Pruebas adecuadas.
- [ ] Logs/métricas sin datos sensibles.
- [ ] Docs/ADR actualizados.
- [ ] Lint, types, tests y build pasan.
- [ ] Sin AI-slop ni dependencia innecesaria.
